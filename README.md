# Sistema de Classificação de Nota em Python

Este repositório contém um exemplo simples em Python desenvolvido durante aula com os alunos do Senac, no dia **13/05/2026**.

O objetivo do código é demonstrar o uso de:

- Entrada de dados com `input()`;
- Conversão de valores para número decimal com `float()`;
- Estruturas condicionais `if`, `elif` e `else`;
- Exibição de mensagens com `print()`.
